ARQUITECTURA BACKEND DESTACADA

OMS Backend · Sistema de Gestión de Órdenes en Tiempo Real

Modernización de gestión de órdenes con base normalizada de 26 tablas en PostgreSQL (3NF), API modular con Node.js, Express y Strapi, Redis Pub/Sub + WebSockets para estados en tiempo real, Docker y testing en Bruno/Postman.

Repositorio OMS (GitHub)
oms-backend · servidor-postgresql bash / node 
Flujo Backend OMS: Creación y notificación de orden en tiempo real
POST /api/orders  -->  Middleware de Validación y Manejo Centralizado de Errores
  ├─ 1. Validación de estructura y stock en PostgreSQL (26 tablas 3NF)
  ├─ 2. Registro de transacción atómica en tablas de órdenes
  └─ 3. Publicación de evento en Redis y emisión bidireccional por WebSockets
