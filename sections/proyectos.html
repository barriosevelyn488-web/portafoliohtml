PROYECTO BACKEND DESTACADO

OMS Backend & Plataforma PostgreSQL

Núcleo backend para un sistema de gestión de órdenes y pedidos en tiempo real. Diseñé y normalicé la base de datos relacional en PostgreSQL, implementé el manejo centralizado de errores, validaciones y servicios con Node.js, Express, Redis y WebSockets. Apoyé en la coordinación de sprints, flujo de trabajo en Git y pruebas de endpoints con Bruno/Postman y Docker.

Repositorio PostgreSQL & Docker Repositorio OMS
oms-backend · servidor-postgresql 
Flujo Backend OMS: Creación y notificación de orden en tiempo real
POST /api/orders  -->  Middleware de Validación y Manejo Centralizado de Errores
  ├─ 1. Validación de estructura y stock en PostgreSQL (Base normalizada 3NF)
  ├─ 2. Registro de transacción atómica en tablas de órdenes
  └─ 3. Publicación de evento en Redis y emisión bidireccional por WebSockets
