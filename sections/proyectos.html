PROYECTO BACKEND DESTACADO

OMS (Organización Mundial de la Salud) Backend – Sistema de Gestión de Órdenes

Liderazgo técnico y desarrollo de backend/API a la medida normalizando una base de datos relacional en PostgreSQL (3NF). Implementación de validaciones robustas y manejo centralizado de errores utilizando Node.js, Express, Redis y WebSockets para notificaciones en tiempo real; configuración del entorno de trabajo y despliegue con Docker, y documentación de pruebas en cada servicio con testing a la medida de cada API (Bruno/Postman).

Repositorio OMS (Backend)
oms-backend · servidor-postgresql bash / node 
Flujo Backend OMS: Creación y notificación de orden en tiempo real
POST /api/orders  -->  Middleware de Validación y Manejo Centralizado de Errores
  ├─ 1. Validación de estructura y stock en PostgreSQL (Base normalizada 3NF)
  ├─ 2. Registro de transacción atómica en tablas de órdenes
  └─ 3. Publicación de evento en Redis y emisión bidireccional por WebSockets
